# AI代码助手 IDEA 插件设计方案

## 一、项目背景与需求

### 1.1 核心痛点
- 开发人员在浏览器中与AI大模型对话获取代码解决方案后，需要手动逐个复制粘贴到项目中
- AI返回的内容格式多样，包含代码片段、修改建议、新文件等
- 手动查找定位和修改代码行效率低下，容易出错

### 1.2 目标用户
- 使用 IntelliJ IDEA 进行开发的程序员
- 需要频繁与 AI 大模型交互获取代码方案
- 项目技术栈：Java + HTML + JavaScript

### 1.3 核心需求
- 便捷收集项目代码片段并生成符合AI理解的上下文
- 规范化AI的输出格式，便于程序解析
- 半自动化应用AI生成的代码变更
- 保留完整的操作历史记录

## 二、解决方案设计

### 2.1 实现形式
采用 **IntelliJ IDEA 插件**形式，原因如下：
- 与开发环境无缝集成
- 可直接操作项目文件
- 充分利用IDEA现有功能
- 用户体验一致性

### 2.2 工作原理
1. **代码收集**：通过编辑器右键菜单收集代码片段
2. **格式规范**：生成标准化的提示词模板
3. **AI交互**：用户复制内容到浏览器与AI对话
4. **结果解析**：解析AI返回的结构化数据
5. **变更应用**：半自动应用代码变更到项目

## 三、功能模块设计

### 3.1 用户界面

#### 工具窗口布局
- **位置**：IDE右侧工具窗口
- **主题管理栏**：支持创建和切换不同的工作主题
- **双面板设计**：
    - 左侧：输入区域（收集的代码和需求）
    - 右侧：输出区域（AI响应内容）
- **操作按钮组**：清空、复制、生成提示词、粘贴、解析、应用
- **状态栏**：显示当前操作状态和统计信息

### 3.2 代码收集功能

#### 右键菜单集成
- 在编辑器中选中代码右键添加"Add to AI Assistant"选项
- 快捷键：Ctrl+Shift+A

#### 收集信息包含
- 代码片段内容
- 文件相对路径
- 代码行号范围
- 编程语言类型

#### 格式化输出示例
```
## 代码片段 #1
文件路径: src/main/java/com/example/UserController.java
代码位置: 第25-35行
[代码内容]

## 我的需求
[用户补充的需求描述]
```

### 3.3 AI交互规范

#### 提示词模板
- 自动生成包含严格格式要求的提示词
- 要求AI以JSON格式返回结果
- 明确定义操作类型：CREATE、UPDATE、DELETE、INSERT、REPLACE

#### JSON响应格式
- 统一的数据结构
- 包含操作类型、文件路径、变更描述
- 根据操作类型包含相应的内容字段

### 3.4 变更应用机制

#### 支持的操作类型
1. **CREATE**：创建新文件
2. **UPDATE**：更新指定行范围
3. **DELETE**：删除文件或代码行
4. **INSERT**：在指定位置插入代码
5. **REPLACE**：替换指定内容

#### 应用流程
- 解析JSON格式的AI响应
- 逐个展示待应用的变更
- 用户确认后执行变更
- 自动触发代码格式化
- 支持撤销操作

### 3.5 历史记录管理

#### 存储位置
- 项目根目录下 `.ai-assistant` 文件夹
- 按主题和日期组织目录结构

#### 目录结构
```
.ai-assistant/
├── config.json          # 配置文件
├── history/            # 历史记录
│   ├── 2024-01-15_用户管理模块优化/
│   │   ├── request_001.md      # 请求内容
│   │   ├── response_001.json   # AI响应
│   │   └── applied_001.log     # 应用日志
│   └── 2024-01-16_支付功能开发/
└── templates/          # 提示词模板
```

#### 记录内容
- 每次生成的请求内容
- AI的响应结果
- 实际应用的变更
- 操作时间戳

## 四、技术架构

### 4.1 技术栈
- **开发语言**：Java21
- **构建工具**：Gradle
- **平台依赖**：IntelliJ Platform SDK
- **UI框架**：Swing + IntelliJ UI Components

### 4.2 利用IDEA现有能力
- **VirtualFile API**：文件系统操作
- **Document/Editor API**：编辑器操作
- **CodeStyleManager**：代码自动格式化
- **CommandProcessor**：支持撤销/重做
- **NotificationGroup**：通知提醒
- **ToolWindow**：工具窗口管理
- **DiffManager**：差异对比展示
- **Git集成**：版本控制支持

## 五、使用流程

### 5.1 标准工作流
1. **收集代码**
    - 在IDEA中选中相关代码片段
    - 右键选择"Add to AI Assistant"
    - 代码自动添加到插件输入区

2. **编辑需求**
    - 在输入区补充具体需求说明
    - 点击"生成提示词"按钮
    - 复制完整内容

3. **AI交互**
    - 在浏览器中粘贴内容给AI
    - 等待AI按格式要求返回JSON

4. **应用变更**
    - 复制AI响应粘贴到输出区
    - 点击"解析"验证格式
    - 点击"应用"执行变更
    - 确认每个变更操作

5. **历史保存**
    - 自动保存到当前主题目录
    - 支持历史记录查看和恢复

### 5.2 快捷操作
- **Ctrl+Shift+A**：添加选中代码
- **Ctrl+Shift+G**：生成提示词
- **Ctrl+Shift+P**：解析并应用

## 六、特色功能

### 6.1 智能特性
- **路径智能匹配**：模糊匹配文件位置
- **冲突检测**：检测文件是否存在或内容是否变化
- **上下文感知**：记住项目结构和用户偏好

### 6.2 安全保障
- **自动备份**：应用前备份原文件
- **回滚机制**：支持一键撤销所有变更
- **确认机制**：危险操作需二次确认
- **语法检查**：应用前验证代码语法

### 6.3 扩展性
- **主题管理**：按功能模块组织历史记录
- **模板系统**：自定义提示词模板
- **批量处理**：支持多文件关联修改

## 七、项目优势

### 7.1 对比手动操作
- **效率提升**：减少90%的复制粘贴操作
- **准确性**：避免手动定位错误
- **可追溯**：完整的操作历史

### 7.2 对比其他方案
- **原生集成**：完全融入IDEA生态
- **半自动化**：保留人工确认环节，更安全
- **格式规范**：统一的交互格式，减少歧义

## 八、后续优化方向

1. **AI直连**：集成API直接调用AI服务
2. **团队协作**：支持共享模板和历史
3. **智能推荐**：基于历史学习用户习惯
4. **多语言支持**：扩展到其他编程语言
5. **批量重构**：支持项目级别的代码重构

## 九、总结

本插件通过深度集成IDEA平台能力，为开发者提供了一个高效的AI辅助编程工具。它不仅解决了代码应用的效率问题，还通过规范化的交互格式和完善的历史管理，让AI辅助编程变得更加可控和可靠。插件采用半自动化的设计理念，在提高效率的同时保证了代码质量和安全性。
